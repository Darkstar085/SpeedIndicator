## ✨ Features

- ⚡ Real-time download and upload speed monitoring
- 📊 Animated live speed waveform
- 📈 Peak speed and active session duration
- 📶 Separate WiFi and mobile data usage tracking
- 📅 Daily, monthly, and historical usage logs
- 🎨 System, light, and dark theme support
- 🌈 Dynamic color support
- 🔔 Optional persistent notification speed monitor
- 🔒 Usage access and battery optimization controls
- 🚀 Foreground service for continuous monitoring
- 🔄 Automatic startup support after device reboot
- 📱 Modern Jetpack Compose and Material 3 UI

## 🚀 Quick Start

### Requirements

- Android Studio
- JDK 17
- Android SDK 37
- Android 8.0 (API 26) or newer

### Clone

```bash
git clone https://github.com/Darkstar085/SpeedIndicator.git
cd SpeedIndicator
```

### Build

```bash
./gradlew assembleDebug
```

The generated debug APK is available under `app/build/outputs/apk/debug/`.

## 💡 Inspiration

The project was inspired by the open-source **[NetSpeedIndicator](https://github.com/ronyaburaihan/NetSpeedIndicator)** project by [ronyaburaihan](https://github.com/ronyaburaihan). It provided useful inspiration for the overall concept of a modern Android network speed and data usage monitor. The UI, architecture, implementation, and feature set in this repository have been developed independently.
